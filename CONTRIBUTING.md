# Contributing to your learning portfolio

This repository is a personal learning tracker. Keep additions accurate, attributable, and easy to revise.

## Content checklist
- [ ] Use the relevant topic or mock-test folder.
- [ ] Explain the concept in your own words.
- [ ] Include steps and units in worked solutions.
- [ ] Add a source link when applicable.
- [ ] Record mistakes and the corrected approach.
- [ ] Update the section README or daily log when progress changes.

## Commit format
`type(scope): short imperative summary`

Examples:
- `docs(percentages): add successive percentage-change notes`
- `feat(ninja-test-01): add mock analysis`
- `fix(data-interpretation): correct chart-reading example`
- `chore(repo): improve topic navigation`
